# Компоненты интерфейса

Страницы `catalog.vue`, `tasks/new.vue` и `tasks/[id].vue` отвечают за загрузку данных,
API-действия и переходы. Компоненты получают типизированные данные через props,
редактируемые значения через `v-model`, а действия передают странице через события.
Компоненты не отправляют запросы и не принимают решения за пользователя.

- `AppCard.vue` — общая оболочка карточки: варианты `outline` и `soft`,
  заголовок и описание через props, слоты `leading`, основной и `footer`.
  При передаче `to` вся карточка становится ссылкой; внутрь такой карточки
  нельзя помещать кнопки, поля ввода или другие ссылки.
- `catalog/CatalogTaskCard.vue` — карточка опубликованной задачи со ссылкой и рейтингом.
- `tasks/TaskRating.vue` — компактный рейтинг или подробная разбивка по полям.
- `tasks/TaskWorkflow.vue` — текущий этап подготовки задачи.
- `tasks/TaskQuestion.vue` — ответ на уточняющий вопрос и состояние сохранения.
- `tasks/TaskCardFields.vue` — поля редактирования карточки.
- `tasks/TaskDetails.vue` — список полей опубликованной задачи.
- `tasks/TaskProposalCard.vue` — один отклик с выбором через `v-model`.
- `tasks/TaskProposalForm.vue` — форма отклика и её валидация.
- `tasks/TaskProposalSelection.vue` — просмотр откликов и ручной выбор бизнеса.
- `AppEmptyState.vue` — пустое состояние или ошибка с опциональным действием.

Модели API и веса полей находятся в `app/types/catalog.ts`. Рейтинг приходит с сервера;
его отображение не ограничивает возможность отклика. Для оформления используются
компоненты Nuxt UI и семантические цвета, поддерживающие светлую и тёмную темы.

Nuxt автоматически добавляет имя папки к имени компонента: например,
`tasks/TaskRating.vue` используется как `<TasksTaskRating>`.

Стили оболочки находятся в `AppCard.vue`, стили вопросов — в `TaskQuestion.vue`.
Они изолированы через `scoped`; глобальный CSS хранит только тему приложения.
