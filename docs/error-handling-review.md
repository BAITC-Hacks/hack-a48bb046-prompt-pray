# Проверка обработки ошибок (T-8)

`ai_service` использует `AppException` и стабильные коды `ai_*`. Тело ошибки
провайдера не передаётся клиенту. Таймаут, недоступность сети, ограничение частоты,
ошибки конфигурации, отказ, незавершённый и некорректный ответ покрыты тестами
`backend/ai_service/tests/test_errors.py` через общий HTTP-обработчик исключений.

`example_service` использует общие `not_found` и `unauthorized`: это предусмотренные
API-стандартом базовые ошибки, поэтому переименование в `item_*` не требуется.
Отсутствующий и чужой объект возвращают одинаковый 404. Ошибки Pydantic остаются
стандартным 422 с массивом `detail`, как требует раздел 4 API-стандарта.
Контракт проверяет `backend/example_service/tests/test_items.py`.

Для этой задачи изменение существующих кодов и публичного контракта не потребовалось.
