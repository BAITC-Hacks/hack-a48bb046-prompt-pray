# docs — стандарты проекта

Документация нацелена на скорость: не пересказывает код, а фиксирует решения и соглашения,
которые нельзя вывести чтением одного файла. Правила самого репозитория (git, доска задач) — в
[`AI.md`](../AI.md). Как устроен и запускается конкретный слой — в его README:
[`backend/README.md`](../backend/README.md), [`frontend/README.md`](../frontend/README.md).

| Документ | О чём |
|---|---|
| [`api-standards.md`](api-standards.md) | Единый контракт API между gateway, сервисами и фронтендом: ошибки, коды, пагинация, версии, аутентификация |
| [`architecture.md`](architecture.md) | Слои внутри сервиса (clean architecture), карта доменных сущностей `AGENTS.md` по сервисам, как добавить сервис |
| [`api-test-texts.md`](api-test-texts.md) | 32 примера запросов для проверки бизнес-описаний, AI-уточнений, языков и валидации API |

Меняете контракт (схему ответа, префикс, код ошибки) — правите документ в том же коммите/PR,
что и код. Документ разошёлся с кодом — исправляет тот, кто это заметил, не откладывая.
